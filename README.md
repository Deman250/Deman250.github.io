# Daniel Mbolonzi — Portfolio

A single-page portfolio site built to showcase my work in Python automation, APIs, and ML-powered tools.

**Live site:**    https://deman250.github.io/portfolio/

## What's on the page

- **A live demo** — the Fitness Coach tool, embedded right on the page so visitors can try it without leaving
- **Services** — three concrete offerings aimed at real problems: automated data reports, API integration scripts, and financial reconciliation scripts (M-Pesa/Sacco-focused)
- **Projects** — links to my four core repos: Fitness Coach (browser-coach), Performance Predictor (smp-tracker), Multi-Source Dashboard (api-dashboard), and Fitness Log Analysis (data-analysis-report)

## Stack

- Plain HTML/CSS — no framework, no build step, single self-contained file
- Dark theme with a warm accent color, monospace tags for a technical feel
- Fully responsive (flex-wrap layout, no fixed widths)
